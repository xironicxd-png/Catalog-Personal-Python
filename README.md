# Catalog-Personal-Python
Un script Python simplu pentru gestionarea notelor și calcularea mediilor anuale, incluzând logica pentru teze și rotunjiri matematice.

## Caracteristici
* Calcularea mediei aritmetice pentru fiecare materie.
* Suport pentru materii cu teză (pondere 3/4).
* Validarea automată a datelor introduse.
* Generarea unui raport final cu media generală.

## Cum se rulează
1. Asigură-te că ai Python instalat.
2. Descarcă `main.py`.
3. Rulează comanda: `python main.py`
